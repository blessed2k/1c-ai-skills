# 1c-dev 0.2: справочные скиллы по стандартам ИТС

## Задача

У мейнтейнера было пять личных справочных скиллов, вынесенных из MCP-сервера: сигнатуры
обработчиков, идиомы BSL, ревью по стандартам, каркас модуля, заготовка теста YAxUnit. Нужно
было решить, какие из них нужны, проверить их по стандартам ИТС и добавить в плагин только то,
что реально помогает агенту.

## Как проверяли

1. Сравнение со скиллом и без него (`claude plugin eval --ablation with-without`), по кейсу на
   тему.
2. Сверка содержимого со стандартами ИТС v8std (#std455, 439, 499, 790, 783, 648, 792, 542,
   642, 487, 678, 669, 794, 733, 726, 436, 737, 773, 464, журнал изменений #std788).

## Что нашли в старых скиллах

- Сигнатуры обработчиков, идиомы и ревью: без скилла агент отвечал так же. При этом в идиомах
  был несуществующий метод `ИнформацияОбОшибке().ПодробноеПредставлениеОшибки()` (трижды),
  обработчик оповещения без `Экспорт`, устаревший вывод ошибки длительной операции, чтение в
  транзакции без блокировки, временный файл вместо потока, путь к файлу параметром сервера.
- Каркас модуля расходился с #std455: не было `ОписаниеПеременных`, `Инициализация`, областей
  таблиц формы, модуля команды; правило «пустые области не удалять» противоречит п. 1.8.
- Заготовка YAxUnit: единственная с измеренной пользой.

## Решение

- Убраны: сигнатуры обработчиков, идиомы, ревью по стандартам.
- `bsl-module-skeleton` переписан по #std455 и #std439.
- `yaxunit-test-skeleton` очищен от правил генератора.
- Новый `bsl-standards`: только темы, где агент ошибается или правило появилось недавно. В
  каждой теме пересказ своими словами, номер стандарта, минимальный пример.
- Ревью-агенты мейнтейнера вызывают `1c-dev:bsl-standards` и `1c-dev:bsl-module-skeleton`.
