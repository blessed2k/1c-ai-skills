# Стандарты 1С, где агент ошибается

Здесь не пересказ всех стандартов, а только темы, где код «по памяти» расходится с актуальными
требованиями 1С. Правила пересказаны своими словами, у каждого номер стандарта ИТС:
`#stdNNN`, полный текст на its.1c.ru/db/v8std (нужна подписка).

## Как применять

1. Определи тему задачи по таблице и прочитай соответствующий файл из `references/` целиком
   **до того, как пишешь код**. Задача задевает несколько тем: прочитай все.
2. Пиши код по правилам файла. Если в конфигурации есть БСП, бери функции БСП, названные в
   файле, а не собственную реализацию.
3. При ревью называй нарушенное правило вместе с номером стандарта.
4. Если правило зависит от версии платформы (так помечено в файле), сверь версию и режим
   совместимости конфигурации (`Configuration.xml`) и не применяй его на более старой.

| Тема | Файл | Когда читать |
|---|---|---|
| Исключения | `references/errors.md` | Попытка/Исключение, ВызватьИсключение, запись ошибки в журнал, сообщение об ошибке пользователю |
| Транзакции и блокировки | `references/transactions.md` | НачатьТранзакцию, чтение данных перед их изменением, БлокировкаДанных |
| Запись регистров | `references/registers.md` | запись наборов записей, особенно в цикле или большими объёмами |
| Файлы | `references/files.md` | временные файлы, двоичные данные, передача файла между клиентом и сервером, пути к файлам |
| Длительные операции | `references/long-operations.md` | фоновое выполнение из формы, ДлительныеОперации БСП |
| Клиент и сервер | `references/client-server.md` | код модуля формы, серверные процедуры, вызываемые с клиента |
| Запросы | `references/queries.md` | остатки регистров, поиск по строке через ПОДОБНО, запросы в цикле |
| Безопасность | `references/security.md` | HTTPS и FTPS, внешние компоненты и паузы, Выполнить/Вычислить, регламентные задания с пользовательскими формулами |
| Обработчики объекта | `references/object-handlers.md` | ПередЗаписью, ПриЗаписи, ПередУдалением, проверки при записи |

## Границы

- Структура модуля и порядок областей: скилл `bsl-module-skeleton`.
- Заготовка юнит-теста: скилл `yaxunit-test-skeleton`.
- Сигнатуры методов платформы: справочник платформы (синтакс-помощник или MCP со справкой по
  API). Если справочник не знает метода, названного здесь (например, режимов замещения),
  справочник может быть старше платформы: сверь версию, а не отбрасывай правило.

Если темы задачи в таблице нет, этот скилл не нужен: не подгоняй под него соседнюю тему.
