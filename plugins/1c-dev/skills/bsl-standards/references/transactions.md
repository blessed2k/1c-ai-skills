# Транзакции, блокировки, ответственное чтение

Стандарты #std783 (транзакции) и #std648 (ответственное чтение).

## Каркас явной транзакции

- `НачатьТранзакцию()` стоит **перед** `Попытка`, вне блока.
- Всё после начала транзакции (блокировка, чтение, запись) находится в одном блоке `Попытка`.
- `ЗафиксироватьТранзакцию()` последняя строка блока `Попытка`.
- В `Исключение` **первой** строкой `ОтменитьТранзакцию()`, затем запись в журнал.
- Если транзакция может быть вложенной (вызывающий код сам в транзакции), в конце блока
  `Исключение` стоит `ВызватьИсключение;`, иначе внешняя транзакция упадёт позже с ошибкой
  «В этой транзакции уже происходили ошибки».
- Начало и фиксация (отмена) в одном методе, пары всегда сбалансированы.

```bsl
НачатьТранзакцию();
Попытка
	Блокировка = Новый БлокировкаДанных;
	Элемент = Блокировка.Добавить("РегистрСведений.СчетчикиЗаявок");
	Элемент.УстановитьЗначение("Подразделение", Подразделение);
	Элемент.Режим = РежимБлокировкиДанных.Исключительный;
	Блокировка.Заблокировать();

	Запрос = Новый Запрос(
	"ВЫБРАТЬ Счетчики.Значение КАК Значение
	|ИЗ РегистрСведений.СчетчикиЗаявок КАК Счетчики
	|ГДЕ Счетчики.Подразделение = &Подразделение");
	Запрос.УстановитьПараметр("Подразделение", Подразделение);
	Выборка = Запрос.Выполнить().Выбрать();
	Значение = 0;
	Если Выборка.Следующий() Тогда
		Значение = Выборка.Значение;
	КонецЕсли;

	Набор = РегистрыСведений.СчетчикиЗаявок.СоздатьНаборЗаписей();
	Набор.Отбор.Подразделение.Установить(Подразделение);
	Запись = Набор.Добавить();
	Запись.Подразделение = Подразделение;
	Запись.Значение = Значение + 1;
	Набор.Записать();

	ЗафиксироватьТранзакцию();
Исключение
	ОтменитьТранзакцию();
	ЗаписьЖурналаРегистрации(НСтр("ru = 'Нумерация заявок'"), УровеньЖурналаРегистрации.Ошибка, , ,
		ОбработкаОшибок.ПодробноеПредставлениеОшибки(ИнформацияОбОшибке()));
	ВызватьИсключение;
```

## Когда транзакция не нужна

- Только запись одного объекта без чтения зависимых данных: платформа сама откроет
  транзакцию при `Записать()`. Явная транзакция здесь лишняя.
- Код вызывается только из `ПередЗаписью`, `ПриЗаписи`, `ПередУдалением`, `ОбработкаПроведения`
  и подписок на них: он уже внутри системной транзакции, свою открывать не нужно. Блокировку
  там ставят без `НачатьТранзакцию`.
- Во время обработки исключения, пока транзакция ещё активна, к базе обращаться нельзя, в том
  числе неявно (например, получая представление ссылки).

## Ответственное чтение

Чтение, по результату которого данные меняются или принимаются решения (проведение,
передача данных наружу, групповая обработка), выполняется **в транзакции и после установки
управляемой блокировки**. Чтение без блокировки даёт гонку: другой сеанс изменит данные между
чтением и записью.

- Читаешь, чтобы потом изменить эти же данные: **исключительная** блокировка до чтения.
  Иначе возможна взаимоблокировка.
- Читаешь, чтобы сформировать другие данные (например, движения по прочитанным остаткам):
  **разделяемая** блокировка на читаемое, исключительная на изменяемое.
- Перед изменением ссылочного объекта, полученного через `ПолучитьОбъект()`, проверь, что он
  не удалён (`Неопределено`), и поставь объектную блокировку
  `ЗаблокироватьДанныеДляРедактирования`.
- Ответственное чтение не нужно для динамических списков, поиска, большинства отчётов,
  условно-постоянных данных, монопольного режима и данных одного пользователя.

## Длительность

- В транзакции только то, что неделимо по бизнес-логике. Независимые действия выполняются
  отдельными транзакциями, при оптимизации допустима порция в одной.
- Порция должна укладываться примерно в 20 секунд под нагрузкой: это время ожидания
  блокировки по умолчанию, дольше другие сеансы получат «Превышено время ожидания установки
  блокировки».
- До начала транзакции выносят: тяжёлые расчёты, проверку заполнения, запросы, которым не
  нужна блокировка.
- Внутри транзакции **нельзя** обращаться к внешним ресурсам: HTTP, веб-сервисы, почта, FTP,
  сетевые папки.
- Отключение итогов регистра (`УстановитьИспользованиеИтогов(Ложь)`) вместе с записью и
  включением итогов выполняется в одной транзакции; пересчёт итогов после неё.
