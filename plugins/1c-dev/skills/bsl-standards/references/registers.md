# Запись регистров сведений и накопления

Стандарт #std792 (опубликован в 2025 году).

## Правила

1. **Не записывать наборы в цикле** по одной или нескольким записям: это в разы медленнее, чем
   один набор. Ориентир: порции примерно по 1000 записей.
2. **Не перезаписывать большой набор**, если меняется не больше 30% записей. Перезапись
   удаляет все записи по отбору и вставляет их заново, а это медленнее и раздувает журнал
   транзакций СУБД. Записывать только изменения.
3. Для записи изменений использовать **режимы замещения** метода `Записать` набора записей:

| Режим | Что делает | Платформа |
|---|---|---|
| `Записать(Ложь)` | только добавляет записи, подходит для пустого регистра | любая |
| `РежимЗамещения.Слияние` | добавляет новые и заменяет существующие записи набора | 8.3.26 и новее |
| `РежимЗамещения.Удаление` | удаляет записи, перечисленные в наборе | 8.3.26 и новее |
| `РежимЗамещения.Обновление` | обновляет существующие записи набора | 8.3.27 и новее |

Перед применением сверь версию платформы и режим совместимости конфигурации. На более старой
платформе этих режимов нет, и справочник API старой версии их тоже не знает.

## Пример: удалить записи по списку одним набором

Неправильно: создавать и записывать пустой набор с отбором для каждого элемента списка.

Правильно:

```bsl
Блокировка = Новый БлокировкаДанных;
Элемент = Блокировка.Добавить("РегистрСведений.НастройкиКоманд");
Элемент.УстановитьЗначение("Пользователь", Пользователь);

НачатьТранзакцию();
Попытка
	Блокировка.Заблокировать();
	Удаляемые = РегистрыСведений.НастройкиКоманд.СоздатьНаборЗаписей();
	Для Каждого Команда Из КомандыКУдалению Цикл
		Запись = Удаляемые.Добавить();
		Запись.Пользователь = Пользователь;
		Запись.Команда = Команда;
	КонецЦикла;
	Удаляемые.Записать(РежимЗамещения.Удаление);
	ЗафиксироватьТранзакцию();
Исключение
	ОтменитьТранзакцию();
	ВызватьИсключение;
КонецПопытки;
```

## Пример: частичное обновление

Когда надо привести набор к новому состоянию, изменения вычисляют запросом на стороне СУБД
(без загрузки всех записей на сервер 1С), а затем пишут двумя наборами: лишние записи через
`РежимЗамещения.Удаление`, новые и изменённые через `РежимЗамещения.Слияние`.

В обработчиках обновления БСП набор с новыми значениями записывают процедурой
`ОбновлениеИнформационнойБазы.ЗаписатьНаборЗаписей(Набор, РежимЗамещения.Обновление)`, а
блокировку по порции ставят через `ЭлементБлокировки.ИсточникДанных` и
`ИспользоватьИзИсточникаДанных`, а не отдельной блокировкой на каждое значение.
