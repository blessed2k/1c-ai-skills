# Клиент и сервер

Стандарты #std487 (минимизация серверных вызовов, п. 12 добавлен в 2023 году) и #std678
(безопасность серверного интерфейса).

## Меньше серверных вызовов

- Открытие формы: данные для неё получают в `ПриСозданииНаСервере` и кладут в реквизиты. В
  `ПриОткрытии` и `ПриПовторномОткрытии` к серверу **не обращаются**. Не надо получать данные
  на клиенте до `ОткрытьФорму`, чтобы передать их параметром: форма получит их сама.
- Функции общих модулей с повторным использованием значений при первом вызове тоже идут на
  сервер: при открытии формы их не вызывают.
- Команда формы: не больше одного серверного вызова.
- Вместо серверного вызова из клиентских `ПередЗаписью` и `ПослеЗаписи` используют
  `ПередЗаписьюНаСервере`, `ПриЗаписиНаСервере`, `ПослеЗаписиНаСервере`, а на клиент данные
  передают через `ПараметрыЗаписи` или реквизиты формы.
- Неявные серверные вызовы с клиента: `ПолучитьИзВременногоХранилища`,
  `УдалитьИзВременногоХранилища`, свойства элементов (`Заголовок`, `Доступность`,
  `ТолькоПросмотр` и др.), получение функциональных опций. Не вызывай их много раз подряд:
  объединяй в один серверный вызов.
- На сервер передают только нужные данные, а не всю коллекцию ради одного поля.
- Параметры процедур и функций, вызываемых с клиента (`&НаСервере`, `&НаСервереБезКонтекста`,
  экспортные методы общих модулей с признаком «Вызов сервера»), объявляют с **`Знач`**: иначе
  платформа гонит значение обратно на клиент, включая содержимое структур и массивов.
  Результат возвращают функцией, а не через параметр.

```bsl
&НаСервереБезКонтекста
Функция ОстатокТовара(Знач Номенклатура, Знач Склад)
	// ...
КонецФункции
```

## Безопасность серверных методов формы

- Любая процедура `&НаСервере` или `&НаСервереБезКонтекста` в модуле формы, **даже не
  экспортная**, может быть вызвана сторонней программой после получения формы, в обход
  клиентских проверок. Экспортные методы модулей с признаком «Вызов сервера» доступны с
  клиента напрямую.
- Поэтому проверки, от которых зависит допустимость действия (даты запрета, права,
  состояние документа), выполняются **на сервере**, внутри того метода, который меняет данные,
  а не только в клиентском обработчике команды.
- Бизнес-логика, не связанная с реквизитами формы, живёт в модулях объектов, менеджеров и
  общих модулях, а не в серверных методах формы.
- Особое внимание к серверным методам, которые включают привилегированный режим.
- На клиент возвращают только итоговый результат расчёта, без промежуточных данных, которые
  могут раскрыть лишнее.
