# Безопасность: HTTPS, внешний код, внешние ресурсы

Стандарты #std669 (внешний код, пп. 7-8 дополнены в 2023-2025 годах) и #std794 (внешние
ресурсы, 2025).

## HTTPS и FTPS

Защищённое соединение создают **с проверкой подлинности сервера** по сертификатам
удостоверяющих центров ОС. Без неё соединение формально шифруется, но сервер не проверяется.
Правило действует для `HTTPСоединение`, `FTPСоединение`, `WSПрокси`, `WSОпределения`.

```bsl
// Без БСП
ЗащищенноеСоединение = Новый ЗащищенноеСоединениеOpenSSL(, Новый СертификатыУдостоверяющихЦентровОС);
Соединение = Новый HTTPСоединение(Сервер, , , , , 30, ЗащищенноеСоединение);

// С БСП
ЗащищенноеСоединение = ОбщегоНазначенияКлиентСервер.НовоеЗащищенноеСоединение();
Соединение = Новый HTTPСоединение(Сервер, , , , , 30, ЗащищенноеСоединение);
```

Код и данные загружают только из доверенных источников и только по защищённым каналам.

## Внешний код

- На сервере нельзя выполнять в небезопасном режиме код, который не входит в конфигурацию:
  внешние обработки и отчёты, расширения, внешние компоненты, введённые пользователем
  алгоритмы и тексты запросов для `Выполнить` и `Вычислить`, пользовательские схемы СКД с
  внешними функциями. С БСП внешний код подключают только через её подсистемы.
- Регламентное задание по умолчанию работает с полными правами, а безопасный режим права не
  урезает. Если задание вычисляет пользовательские формулы, запускай его под служебным
  пользователем без ролей: данные читай и пиши в привилегированном режиме, формулу считай в
  безопасном. С БСП в начале обработчика задания вызывают
  `РегламентныеЗаданияСервер.УстановитьСлужебногоПользователяРегламентногоЗадания`.

## Внешние ресурсы

- Вместо внешних компонент, программ ОС и COM используй средства платформы, где они есть.
  Например, паузу делают методом `ВызватьПаузу`, а не через ОС или COM. Метод работает там,
  где нет вызова с клиента (фоновые задания, HTTP- и веб-сервисы), в остальных местах он
  вызывает исключение.
- С БСП используемые внешние ресурсы перечисляют в `РаботаВБезопасномРежимеПереопределяемый`,
  а при включении функции, которой они нужны, запрашивают разрешение администратора через
  `РаботаВБезопасномРежимеКлиент`.
