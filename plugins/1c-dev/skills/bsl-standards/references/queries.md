# Запросы

Стандарты #std733 (виртуальная таблица «Остатки»), #std726 (ПОДОБНО, дополнен в 2022 году),
#std436 (однотипные запросы, дополнен в 2023 году).

## Текущие остатки

Самый быстрый путь, когда платформа читает хранимую таблицу текущих остатков без
группировки, получается только при трёх условиях одновременно:

- у таблицы `Остатки` **не указана дата** (нужны текущие остатки: первый параметр пустой);
- у регистра не используется разделение итогов;
- внешний запрос использует **все измерения** регистра (в выборке или в условиях соединения).

```bsl
ВЫБРАТЬ
	Номенклатура.Ссылка КАК Товар,
	ЕСТЬNULL(Остатки.КоличествоОстаток, 0) КАК Остаток
ИЗ
	Справочник.Номенклатура КАК Номенклатура
		ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки(, Склад = &Склад) КАК Остатки
		ПО Остатки.Номенклатура = Номенклатура.Ссылка
			И Остатки.Склад = &Склад
```

Отбор по измерениям задают в параметрах виртуальной таблицы, а не в `ГДЕ`. Условие `Склад`
повторено в соединении, чтобы внешний запрос использовал все измерения.

## ПОДОБНО

- Шаблон только строковым литералом или параметром. Нельзя собирать шаблон в тексте запроса
  (`&Шаблон + "%"`, поле таблицы, конкатенация).
- Только `%` и `_`. Конструкции `[...]` и `[^...]` не работают на части СУБД.
- Длина шаблона не больше 1024 символов.
- **Текст, введённый пользователем, экранируют**: спецсимволы `_ % [ ] ^` иначе ломают поиск,
  а на PostgreSQL запрос падает с ошибкой регулярного выражения. `УстановитьПараметр` сам
  ничего не экранирует.

```bsl
Запрос.Текст =
"ВЫБРАТЬ Номенклатура.Ссылка КАК Ссылка
|ИЗ Справочник.Номенклатура КАК Номенклатура
|ГДЕ Номенклатура.Наименование ПОДОБНО &Шаблон СПЕЦСИМВОЛ ""~""";
Запрос.УстановитьПараметр("Шаблон",
	"%" + ОбщегоНазначения.СформироватьСтрокуДляПоискаВЗапросе(ТекстПоиска) + "%");
```

Без БСП экранирующую функцию пишут сами: удваивают `~`, затем ставят `~` перед `%`, `_`, `[`,
`]`, `^`. Сравнение в `ПОДОБНО` не учитывает регистр.

## Однотипные запросы

- Однотипные данные получают **одним** запросом: условие `В (&Список)`, `ОБЪЕДИНИТЬ ВСЕ`,
  пакет запросов. Запрос в цикле по элементам списка это ошибка.
- С БСП используют функции для списков объектов: `ОбщегоНазначения.ЗначениеРеквизитаОбъектов`
  вместо `ЗначениеРеквизитаОбъекта` в цикле.
- **Запрос в цикле допустим** (не отмечай его на ревью как ошибку), если:
  - единый запрос заметно сложнее в разработке;
  - единый запрос медленнее, например, с виртуальными таблицами на разные даты;
  - это порционная обработка большого объёма: обработчики обновления, групповое
    проведение и изменение, удаление помеченных, загрузка из файлов и внешних источников.
