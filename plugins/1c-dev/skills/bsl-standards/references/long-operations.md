# Длительные операции

Стандарт #std642 (пример обработки ошибки обновлён в 2024 году).

## Когда

Серверный вызов, который в обычной работе может длиться больше **8 секунд** (отчёт, групповая
обработка, загрузка и выгрузка, заполнение больших табличных частей), выполняют асинхронно в
фоновом задании. Иначе браузер или веб-сервер оборвут запрос, а пользователь не сможет
отменить операцию.

## Как устроено

- Длительный код лежит в общем модуле или модуле менеджера и кладёт результат во временное
  хранилище. Фоновое задание вызывает только методы общих модулей, поэтому метод модуля
  менеджера вызывают через обёртку (с БСП это делает сама библиотека по полному имени метода).
- После запуска сервер ждёт задание около 0.8 секунды. Не успело: клиент опрашивает его с
  растущим интервалом и показывает индикатор (для отчётов в поле табличного документа, иначе
  форму ожидания с кнопкой «Отмена»).
- Запускать задание из `ПриОткрытии` нельзя (это лишний серверный вызов): запускают в
  `ПриСозданииНаСервере`, а ожидание начинают в `ПриОткрытии`.

## С БСП

Три части: запуск на сервере, ожидание на клиенте, обработка результата.

```bsl
&НаКлиенте
Процедура Рассчитать(Команда)
	Операция = НачатьРасчетНаСервере();
	ПараметрыОжидания = ДлительныеОперацииКлиент.ПараметрыОжидания(ЭтотОбъект);
	Оповещение = Новый ОписаниеОповещения("ПриЗавершенииРасчета", ЭтотОбъект);
	ДлительныеОперацииКлиент.ОжидатьЗавершение(Операция, Оповещение, ПараметрыОжидания);
КонецПроцедуры

&НаСервере
Функция НачатьРасчетНаСервере()
	ПараметрыВыполнения = ДлительныеОперации.ПараметрыВыполненияФункции(УникальныйИдентификатор);
	Возврат ДлительныеОперации.ВыполнитьФункцию(ПараметрыВыполнения,
		"Обработки.РасчетПотребности.РассчитатьПотребность", Период, Склад);
КонецФункции

// Параметры:
//  Результат - см. ДлительныеОперацииКлиент.НовыйРезультатДлительнойОперации
//  ДополнительныеПараметры - Неопределено
//
&НаКлиенте
Процедура ПриЗавершенииРасчета(Результат, ДополнительныеПараметры) Экспорт
	Если Результат = Неопределено Тогда // отменено пользователем
		Возврат;
	КонецЕсли;
	Если Результат.Статус = "Ошибка" Тогда
		СтандартныеПодсистемыКлиент.ВывестиИнформациюОбОшибке(Результат.ИнформацияОбОшибке);
		Возврат;
	КонецЕсли;
	ЗагрузитьРезультат(Результат.АдресРезультата);
КонецПроцедуры

&НаСервере
Процедура ЗагрузитьРезультат(Адрес)
	Потребность = ПолучитьИзВременногоХранилища(Адрес);
	УдалитьИзВременногоХранилища(Адрес);
	// заполнение формы
КонецПроцедуры
```

Обрати внимание:

- обработчик завершения, вызываемый через `ОписаниеОповещения`, объявлен с `Экспорт`, иначе
  платформа его не найдёт;
- статус `"Ошибка"` проверяется всегда: иначе ошибка в задании пройдёт незаметно;
- ошибку выводит `СтандартныеПодсистемыКлиент.ВывестиИнформациюОбОшибке`, а не
  `ВызватьИсключение` с кратким текстом;
- результат забирают из хранилища **и сразу удаляют**, иначе при повторных запусках память
  формы растёт. Если результат нужен несколько вызовов, заранее резервируют один адрес
  хранилища в `ПриСозданииНаСервере` и передают его в `ПараметрыВыполнения.АдресРезультата`.

## Монопольный режим

- Код, который сам (без пользователя) запускает фоновые задания или пишет в базу, сначала
  проверяет `МонопольныйРежим()` и в монопольном режиме ничего не делает.
- Если длительной операции нужен монопольный режим, его устанавливают **до** запуска задания
  (задание его наследует), а интерфейс на время блокируют целиком.
