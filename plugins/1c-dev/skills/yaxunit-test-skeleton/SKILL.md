# Каркас теста YAxUnit

Регистрация тестов, имена процедур и форма утверждения в YAxUnit жёсткие, и по памяти их
путают со старыми фреймворками. Шаблон и правила в `references/skeleton.md`.

## Как применять

1. Вход: имя тестируемого метода и список сценариев (короткие имена проверок:
   `БезСкидки`, `ПустаяТаблица`). Сценариев нет: один сценарий `ВозвращаетОжидаемыйРезультат`.
2. Прочитай `references/skeleton.md` и собери модуль по шаблону.
3. Утверждение-заглушку оставь в каждом тесте, если ожидаемый результат неизвестен: его
   заполняет автор теста. Если результат известен из задачи, напиши настоящее утверждение.

## Границы

- Пользовательские сценарии в интерфейсе, feature-файлы: Vanessa Automation, скилл
  `vanessa-pitfalls`.
- Запуск прогона YAxUnit в этот скилл не входит: так и скажи.
- Хуки (`ПередВсемиТестами` и др.), наборы, теги и другие утверждения в шаблон не входят.
  Добавляй их, только если попросили, и сверяйся с документацией YAxUnit.
