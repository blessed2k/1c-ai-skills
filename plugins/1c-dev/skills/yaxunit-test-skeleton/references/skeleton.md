# Шаблон тестового модуля YAxUnit

## Правила

1. Регистрация тестов только в экспортной процедуре `ИсполняемыеСценарии` цепочкой
   `ЮТТесты.ДобавитьТест("<ИмяТеста>")`, точка с запятой после последнего вызова.
2. Имя теста: `<Метод>_<Сценарий>`. Если метод не задан, просто `<Сценарий>`.
3. Имя сценария превращают в идентификатор: убирают пробелы и все символы, кроме букв, цифр и
   `_`; если имя начинается с цифры, впереди ставят `_`. Сценарий, от которого ничего не
   осталось, пропускают; одинаковые имена не дублируют.
4. Каждый тест: **экспортная** процедура без параметров, над ней комментарий
   `// Проверяет <Метод>: <исходное имя сценария>.`
5. Внутри теста разметка `// Дано`, `// Когда`, `// Тогда` через пустую строку и утверждение
   сразу под `// Тогда`.
6. Утверждения строятся от `ЮТест.ОжидаетЧто(<значение>)`, например `.Равно(<ожидаемое>)`.
7. Отступы табуляцией, цепочка `.ДобавитьТест` с двумя табуляциями.
